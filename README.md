# Gluedle

Gluedle 是一个不播放音频的歌曲资料推理游戏。玩家从公开歌曲题库中选择歌曲进行猜测，根据发行日期、时长、歌词语言、项目分类、演唱关系和创作信息等元数据反馈，逐步缩小答案范围，并在最多 8 次尝试内找到目标歌曲。

Gluedle 不托管歌曲音频或完整歌词；部分回合会在玩家主动解锁后展示短歌词提示。分享结果只展示猜测状态，不公开答案或歌曲标识。

## 开发

项目使用 Vite 与严格模式 TypeScript（`strict: true`），建议使用 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

提交前运行完整检查：

```bash
npm run check
```

该命令依次执行页面契约检查、TypeScript 类型检查、Node 测试和生产构建。
