# Gluedle

Gluedle 是一个每日猜歌网页游戏原型：玩家从很短的歌曲片段开始，在最多 6 次尝试内猜出当天的歌曲。当前版本聚焦于 Curley G 主题的视觉与核心交互验证。

## 当前状态

这是项目的 `v0.1.0` 基础版本，已经包含：

- 响应式单页游戏界面；
- 播放、暂停、帮助与提交猜测的演示交互；
- Gluedle 的基础视觉规范；
- Vite 本地开发与生产构建；
- GitHub Actions 构建检查。

目前的播放和猜测逻辑仍是视觉原型，不包含真实音频、歌曲目录、每日题目或服务端判定。

## 本地开发

需要 [Node.js](https://nodejs.org/) `20.19+`、`22.12+` 或更高版本。

```bash
npm install
npm run dev
```

Vite 会输出本地访问地址，通常为 `http://localhost:5173`。

## 可用命令

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动本地开发服务器 |
| `npm run build` | 生成 `dist/` 生产构建 |
| `npm run preview` | 本地预览生产构建 |
| `npm run check` | 执行当前项目检查 |

## 下一阶段

建议按下面的顺序推进：

1. 拆分页面样式、交互与游戏领域逻辑；
2. 定义歌曲、答案别名、每日题目和尝试记录的数据模型；
3. 接入已获授权的音频片段与正式品牌资产；
4. 增加本地进度保存、胜负状态和分享结果；
5. 补充自动化测试并选择部署平台。
