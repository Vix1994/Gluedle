# Gluedle brand spec

## Current direction

- Product: Gluedle, a Curley G song-guessing game prototype.
- Visual reference: the public `Glue` / `Green to Blue` concept.
- Tone: intimate, fluid, connected, lightly playful.

## Assets

- Official artist logo: pending user-provided or approved source.
- Official `Glue` artwork: pending local asset capture/approval.
- Current v0 uses a neutral Gluedle wordmark and abstract liquid forms so it does not redraw or impersonate official artist marks.

- Paper: `#EEF0E8`
